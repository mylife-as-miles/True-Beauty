# Engineering decisions

2026-11-02, initial development rounds.

1. Preserve full product scope in a219-capability inventory; implement connected local workflows while explicitly blocking unavailable providers and unvalidated classifiers. No cosmetic fallback is labelled a clinical result.
2. React19/Vite7/TypeScript5.9, Tailwind4 custom design system, Dexie4, Zod4 and Zustand5 are installed with a lockfile and verified together. Custom Canvas/WebGL geometry is currently more direct than a Three.js scene; Three/R3F are available but no unnecessary3D dependency is put in the initial UI.
3. Real source reuse from all four pinned repositories, with full retained notices where present. Upstream Virtual Makeup's missing LICENSE file and separate model/asset rights remain distribution blockers. No scraped Skyn datasets/weights or upstream uncertain raster assets.
4. One Tasks Vision pipeline, CPU worker baseline: headless GPU inference unsupported/unpredictable; actual worker benchmarks preserve UI responsiveness. Face, hair and hands share input coordination but use independent cadence. Temporal hair smoothing does not claim optical flow.
5. Hardware WebGL2 is the adaptive material path. Measured software GPU cost selects Canvas by default. Round05 adds honest approximate reflective Canvas finishes and an explicit enhanced-materials choice using actual bounded WebGL2 even on software; both paths share pigment math. OpenCV masking is optional because its512px masks measured slower than Canvas in this environment, while offering an independently testable precision route.
6. Skyn classifiers are not deployed without licensed training/evaluation evidence. Its deterministic k-means and feature/cosine recommendation logic are operational instead; user correction and self-report are authoritative.
7. Current official YouCam docs replace MIROIR's stale file endpoint. Paid requests require server-held credential, reviewed SKU hash/plan, one-use quote, explicit image/credit authorization and spending reservation; no key/no authorization means no remote operation.
8. Taste framed-sheet direction + original pigment-derived palette and editorial fonts. Proofline selection lenses inform ingredient exploration; Common Table continuity informs preserving the current scene across products/wardrobe. No restricted reference code copied.
9. Independent review exposed consent TOCTOU, revoked prose reimport and late camera leaks. Fixed with atomic consent/write transactions, import dependency filtering and shared camera lifecycle; exact adversarial regressions retained.
10. Split comparison must be in display space. A static source fraction is wrong under object-fit cropping and zoom. Map the visible slider through drawn image scale; ResizeObserver invalidates the static frame after resize.
11. Local sample catalogue never claims current prices, inventory, exact dupes or checkout. NGN/USD are separate illustrative amounts, not exchange conversions. Missing GBP/EUR prices are explicitly unavailable.
12. Production offline shell is built from the real asset graph. Vite development HMR is not a reliable offline target. Restrict Vite/Tailwind watchers to exclude Playwright trace HTML, which caused real reload loops during early tests.
13. No remote deployment/push/publishing or paid requests in this checkpoint. No background completion claim; persistent files preserve exact next tasks.

14. Round05 follows renewed user priority for immersive UI/UX before the queued bag-variant task. Keep a bounded mirror/editor workspace, context-at-selection lenses and state continuity. Proofline/Common Table are independently implemented interaction references, not copied source/assets.
15. Share immutable still-portrait snapshots with all look previews, guarding source identity and cloning the mutable vision result. Camera frames remain outside that portrait gallery and outside Dexie. Editor undo stores parameters/light, not raw image or tracking data; delete-all clears it.
16. Separate creative light grading from analysis. Skin Lab always reads the original source. Full portrait/fill modes and zoom use actual object-fit geometry for split/pointer coordinates. Restrict the single-character F shortcut to the editor focus scope; move/restore focus explicitly.
17. A renderer quality switch must not change shade families. Independent criticism reproduced soft-light Canvas vs GLSL hue divergence; Canvas now uses the same numerical pigment formula. Verified digital sample parity is not a calibrated physical shade-match claim.

18. Round06 explicit user authorization enabled bounded paid verification and public Sites hosting. Persist one Site identity and preserve its requested public audience; distinguish static publication from hosted paid capability.
19. Successful provider execution must have genuine receipts, not mocks. Original synthetic fixtures avoid transmitting private/stock subjects. A failed whole-body clothing setting removed trousers; use explicit upper-body category for a blouse. Skin's real face-too-small failure led to visible local landmark framing, not repeated blind retries or invented scores.
20. Current Fastify cannot run unchanged under workerd. Actual native NodeHTTP works, but find-my-way runtime code generation fails. Retain local Fastify; migrate typed workflows to native Fetch with explicitly awaited durable reservations and shared task/session storage. Never cast async D1 into the synchronous ledger interface or enable anonymous public spending.
21. New local domains remain connected to the same source and scene. Persist provenance for generated images in every destination; ordinary source/camera labels must not silently erase generation. Creative grading remains excluded from Skin analysis. Manual composition, live AR and generative previews stay visibly distinct.
22. Independent R06 critique is a real defect-discovery gate. Export/import image smuggling, future/imported prices, concurrent deletion, active-route mobile navigation, missing correction previews and source provenance received reproductions and regression tests. Improvements do not remove unverified device, fairness, licensing or full-scope gates.
